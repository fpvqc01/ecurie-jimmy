# Contraintes FTMO utiles (statique — vérifier avant un achat réel)

Ces points cadrent les idées ; ce ne sont pas des pages scrapées chaque jour.

## Objectifs typiques (ordre de grandeur 2-Step)

- Challenge / Verification : cible de profit (souvent ~10 % / ~5 % selon produit)
- Perte journalière max ~5 %, perte totale max ~10 % (vérifier le produit exact)
- Compte financé : pas de cible de profit obligatoire, mais limites de perte toujours actives

## Rewards (cash)

- Demande possible à partir du **14e jour** après le 1er trade sur le compte, positions fermées
- Review ~1–2 jours ouvrés puis payout ~1–2 jours après facture
- Split : souvent 80 % (2-Step) → 90 % via Scaling / Premium ; 1-Step / Instant souvent 90 %
- Instant : Maximum Loss **ne reset pas** au payout — attention au retrait
- Scaling (Challenge accounts) : 4 mois, +10 % net, ≥2 Rewards traités, balance positive → +25 % taille

## Produit pour l’écurie Jimmy

- **2-Step Swing** : compatible nuit / week-end / news une fois financé
- Éviter 1-Step pour ce système (pas de Swing financé)
- Plafond capital simulé par trader/stratégie : vérifier FAQ (~400k cité en comité)

## Ce que « max cash » veut dire ici

1. Passer le challenge (taux de réussite × taille × coût)
2. Survivre financé (durée de vie × rendement)
3. Demander les Rewards (cash + conditions scaling)
4. Scaler le capital (compose) sans violer les limites

Pas : fraude, partage de compte, hedge multi-comptes interdit, faux KYC.
