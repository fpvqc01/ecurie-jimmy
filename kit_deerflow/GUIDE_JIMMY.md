# Kit d'installation DeerFlow 2 — mode d'emploi (pour Jimmy)

## Sur le nouveau laptop, dans l'ordre :
1. Installer Claude Code (claude.com/claude-code) et se connecter.
2. Copier ce dossier complet (DeerFlow_Kit_Installation) sur le laptop —
   par OneDrive/Google Drive, ou en clonant le depot GitHub prive
   (le kit y est aussi : dossier kit_deerflow/).
3. Ouvrir Claude Code DANS ce dossier, puis coller tout le contenu de
   PROMPT_POUR_CLAUDE_CODE.md comme premier message.
4. Suivre ses instructions. Il faudra creer TOI-MEME :
   - un compte API (DeepSeek recommande : platform.deepseek.com,
     ~2 $ de credit) et generer une cle ;
   - eventuellement installer Docker Desktop si le laptop a assez de RAM.
5. A la fin : rapporter le fichier RAPPORT_DEERFLOW_*.md sur le laptop
   de trading et me le montrer dans notre session principale.

## Rappels
- Cout estime d'une analyse complete : moins de 1 $ avec DeepSeek.
- ATTENTION : si « l'autre laptop » est celui du travail (Tech HFC),
  reflechis avant — un ordinateur d'employeur appartient a l'employeur,
  et ta strategie est privee. Ideal : un laptop personnel.
- Le dossier Analyse_Externe_Ecurie ne contient QUE des copies : rien de
  ce que DeerFlow fera ne peut toucher les ecuries reelles.
